# 发布边界、DMCA 与隐私材料

分析对象是 **realme GT5 Pro（RMX3888）** 上的指定版本；分析方式是 **Codex + ADB + su**。此文说明本仓库如何限定分发范围，不提供法律免责承诺。

## 可能涉及第三方版权／DMCA 争议的材料

| 材料 | 本仓库是否分发 | 复现方式 |
|---|---|---|
| 原始 SystemHelper APK、其它版本 APK、拆分包、固件镜像 | **不分发** | 从自己有权使用的设备或固件自行提取 |
| classes.dex、ODEX/VDEX、原生 SO、厂商 SDK 二进制 | **不分发** | 自行从合法取得的 APK／固件提取 |
| 完整 JADX／Smali 反编译代码、DEX 指令转储 | **不分发** | 对自己的样本运行反编译／反汇编工具 |
| 完整 AndroidManifest、图标、资源、assets 与内置 pub.cer 文件 | **不分发** | 自行解包；本仓库只公开必要字段和证书指纹元数据 |
| 其它 GitHub 仓库的完整源码、报告及固件清单 | **不分发** | 通过固定提交链接阅读原仓库，并遵守其原许可证 |
| 原创分析、调用链、字段名、方法定位、样本哈希 | 分发 | 对关键技术结论限定样本与证据级别 |
| 精选并脱敏的本机权限／AppOps／闹钟／网络统计日志 | 分发 | 明确是摘录与脱敏，保留来源行号；不声称完整原始文件 |
| 完全合成示例与原创离线汇总脚本 | 分发 | 不包含真实设备载荷和厂商公钥；无自动生产端点发送器 |

列为“可能涉及争议”不等于认定这些材料每次分发都构成侵权；具体许可、合理使用、引用范围和所在法域需要分别判断。这里采用不分发完整第三方作品的方式降低争议。

## WTFPL 的范围

WTFPL v2 可用于原创文字和脚本，官方 FAQ 说明它也适用于文档。其许可文本不自带无保证条款，本项目将现状提供说明写在 NOTICE，不修改许可证原文。

本项目只能许可自己拥有或可授权的权利；WTFPL 不能覆盖厂商 APK、第三方 SDK 或外部研究的版权，也不会自动消除 DMCA 反规避条款、隐私或其它法律问题。署名 Codex 不表示 OpenAI 官方背书。

## 不公开的实机敏感材料

原始数据库、待上报 JSON 明细、完整日志、PCAP、IMEI／IMSI／ICCID、实际经纬度、用户 IP、SSID／BSSID、设备序列号、账号及具体第三方应用名称与包名都不随仓库分发。

按设备所有者要求，公开日志中移除所有其它应用记录和应用使用明细；只保留 SystemHelper 相关权限、AppOps、闹钟和目标 UID 网络统计。不是凭关键词删掉部分软件后就把其它原始数据上传。

原始证据保存在仓库外。公开日志是重新生成的副本；没有为了发布而删除本机原始取证材料。`.gitignore` 只作辅助，不能替代逐文件审阅和 Git 历史检查。

## 投诉与结论表述

原创研究或有限引用也可能收到投诉。GitHub 通知下架与法院侵权判决是不同事项；反通知有真实身份、宣誓和司法管辖等要求，应对具体通知认真评估。避免把“研究用途”“非商业”或许可证当成自动免责。

报告应保留以下限定：代码能力≠实机执行，实机缓存≠已上传成功，HTTP 200≠服务端业务接受／入库，单机重启正常≠所有通信场景／ROM 安全。
