# 公开数据说明

此目录仅含人工选择的结构化元数据与汇总，不含原始手机载荷。

- sample.json：realme 原样本版本、哈希、证书指纹与指定机型。
- sample-redmi-20260313.json：Redmi K40 新样本，含来源自述、签名验证路径和静态范围。
- sample-comparison.json：两份 APK 的字段、权限、文件、协议比较与方法定位，不含原代码。
- observations.json：仅 realme 的记录数量、非零使用时长的项数、网络字节总量及验证边界。
- synthetic-response.json：仅 realme 分析阶段的一条历史合成请求的精简响应记录，无真实设备数据。
- github-sources.json：外部仓库固定提交、文件路径和命中行；没有复制原文件内容。

实机原始日志的脱敏摘录另见 logs/。具体应用名称与包名、设备／SIM 标识和位置均不公开。
